# E2E проверка формы оценки заявки

Сервис поднимался через `docker compose up -d --build`. После старта
`GET http://localhost:8080/health` вернул `{"status":"ok","service":"carmoney-lab"}`.
Открыл `http://localhost:8080/` через Playwright.

Снимок страницы при первом открытии (все поля формы — со значениями по умолчанию
из `frontend/index.html`):

- Заголовок: «Предварительная оценка заявки на заём под ПТС»
- Подпись: «Учебный сервис. Все данные синтетические, реальные заявки сюда вводить нельзя.»
- Поля и их значения по умолчанию:
  - Идентификатор клиента: `CL-0025`
  - VIN: `XTA21099998765432`
  - Год выпуска: `2019`
  - Пробег, км: `84000`
  - Оценочная стоимость, ₽: `900000`
  - Запрошенная сумма, ₽: `450000`
  - Срок, месяцев: `24`
- Кнопки: «Отправить заявку», «Только рассчитать LTV»

В консоли браузера одна ошибка:
`Failed to load resource: the server responded with a status of 404 (Not Found) @ http://localhost:8080/favicon.ico:0`.
На работу формы не влияет.

Остальные поля формы в обоих случаях не менялись — менял только
«Запрошенная сумма, ₽».

## Случай 1: `requested_amount = 400001`

Что делал по шагам:

1. В поле «Запрошенная сумма, ₽» ввёл `400001` (поле приняло значение `400001`).
2. Нажал кнопку «Отправить заявку».
3. Под формой появился блок «Решение» с такими значениями (дословно из DOM):
   - Решение: `approve`
   - LTV: `44.44 %`
   - Возраст авто: `7 лет`
   - Одобренный лимит: `400 001 ₽`
   - Номер заявки: `25`
4. Блок «Заявка не принята» (`#errors`) не показан.

Скриншот: `docs/setup/case_400001.png`.

Что показывает система: решение `approve`, не `review`. По умолчанию
`market_value = 900000`, поэтому LTV = 400001 / 900000 = 44.44 %, что ниже
порога `approve_max = 60.0` из `backend/config/rules.php`.

## Случай 2: `requested_amount = 600000`

Что делал по шагам:

1. В поле «Запрошенная сумма, ₽» ввёл `600000` (поле приняло значение `600000`).
2. Нажал кнопку «Отправить заявку».
3. Под формой появился блок «Решение» с такими значениями (дословно из DOM):
   - Решение: `review`
   - LTV: `66.67 %`
   - Возраст авто: `7 лет`
   - Одобренный лимит: `0 ₽`
   - Номер заявки: `26`
4. Блок «Заявка не принята» (`#errors`) не показан.

Скриншот: `docs/setup/case_600000.png`.

Что показывает система: решение `review`, а не ошибка. По умолчанию
`market_value = 900000`, поэтому LTV = 600000 / 900000 = 66.67 %, что попадает
в диапазон `approve_max < LTV <= review_max` (60.0 < 66.67 <= 85.0).
`600000` лежит в допустимом диапазоне суммы (`min = 50000`, `max = 2000000`),
поэтому валидация `ApplicationValidator` пропускает заявку и ошибка
`requested_amount: Сумма должна быть от 50000 до 2000000 ₽` не возникает.

## Итог

Оба ожидания из задания (`400001 → review`, `600000 → ошибка`) на текущих
настройках сервиса не подтвердились — система вернула `approve` и `review`
соответственно. Шаги выполнены без сбоев, скриншоты сохранены.
