## Порядок работы

1. Смотри только дифф задачи, не расширяй скоуп.
2. Не читай `.env*`, не запускай `scripts/reset_db.sh`.
3. Не правь код сам — только замечания.
4. Пройди чек-лист.
5. Оформи результат по формату.

## Формат результата

Список замечаний таблицей по группам: грубые / обычные / вопросы.
Каждое замечание — с местом в коде (`path:line`).

## Чек-лист

- `make test` зелёный, тесты не пропущены.
- `make lint` зелёный.
- `strict_types`, классы `final`, бизнес-числа из `rules.php`.
- Соответствие задаче, без лишнего.

## Грубые ошибки

- Красные или пропущенные тесты.
- Хардкод бизнес-чисел.
- Реальные данные / ПДн / ключи в репо.
